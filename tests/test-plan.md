# 📋 Plan de Tests — Liste de Cadeaux

## Tests de tri
- [ ] Tri croissant affiche du moins cher au plus cher
- [ ] Tri décroissant affiche du plus cher au moins cher
- [ ] Tri par défaut rétablit l'ordre original
- [ ] Le tri fonctionne avec un filtre actif

## Tests de filtre
- [ ] Filtre "Tous" affiche tous les cadeaux
- [ ] Filtre "Sport" n'affiche que les articles Sport
- [ ] Filtre "Mode" n'affiche que les articles Mode
- [ ] Filtre "Loisir" n'affiche que les articles Loisir
- [ ] Changement de filtre met à jour l'affichage

## Tests de dépendance
- [ ] Clic sur cadeau avec dépendance ouvre la pop-up
- [ ] La pop-up affiche les dépendances correctement
- [ ] Clic sur "Voir le produit" ouvre le lien
- [ ] Clic sur "Retour" ferme la pop-up
- [ ] Clic en dehors ferme la pop-up
- [ ] Touche Échap ferme la pop-up

## Tests de responsive
- [ ] Le site s'affiche correctement sur mobile
- [ ] Les boutons sont cliquables sur tactile
- [ ] Les images sont responsive

## Tests d'accessibilité
- [ ] Navigation clavier fonctionnelle
- [ ] aria-labels présents sur les boutons
- [ ] aria-pressed sur le bouton de tri
- [ ] loading="lazy" sur les images
